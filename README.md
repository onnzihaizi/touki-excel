# 登記簿 → CS Excel 自動入力 無料版 Ver.3.3

## 今回の変更
- マンションナビへの依存・検索処理を削除しました。
- 建物管理会社と総戸数は、物件名＋所在地を使った一般Web検索から取得します。
  - 建物管理会社: 1件目 C7 / 2件目 F7 / 3件目 I7 / 4件目 L7
  - 総戸数: 1件目 D2 / 2件目 G2 / 3件目 J2 / 4件目 M2
  - 見つからない項目は空欄です。
- C15/F15/I15/L15 は「借入開始時期」ではなく「購入時期」になりました。
  - 登記簿の甲区から、現在所有者の取得原因日（売買・相続など）を読み取ります。
  - 現在有効な抵当権がなくても購入時期は入力されます。
- 毎月返済額は従来どおり C19/F19/I19/L19 です。

## 起動
`起動.command` をダブルクリックしてください。

## 注意
管理会社・総戸数は一般Web検索結果から抽出するため、検索サイト側の表示変更やネットワーク状況によって取得できない場合があります。その場合は空欄で出力し、画面から手入力できます。


## Ver.3.3 追加
- D3/G3/J3/M3: 現在の築年数（現在年 - 築年）
- C10/F10/I10/L10: 実行日から2か月後の年月（YYYY/M）
- C17/F17/I17/L17: 購入時期 + 35年の完済想定年月（YYYY/M）
- C26/F26/I26/L26: 想定固定資産税の月額（数字のみ）
  - 登記簿だけでは固定資産税評価額が分からないため、抵当権の債権額を参考価格として「70% × 標準税率1.4% ÷ 12」で簡易推定します。
  - 根拠となる抵当権額が取れない場合は空欄。画面で修正可能です。
