# 登記簿 → CS Excel Ver.3.8.15

Ver.3.8.13の機能・計算ロジックを維持したまま、以下を更新した版です。

## Ver.3.8.15 変更点
- Excelテンプレートをユーザー指定の最新版「最新版テスト(4).xlsx」に差し替え
- ダウンロードするExcelのファイル名を、1件目の登記簿の「現所有者名」から自動生成
  - 例：現所有者が「藤岡綱昭」なら `CS_藤岡綱昭様.xlsx`
  - 現所有者名を取得できない場合は `CS_登記簿自動入力.xlsx`
- ファイル名に使用できない記号は自動除去

## 維持している仕様
- 最大7物件を1つのExcelへ出力
- 部屋番号は「113号室」の形式
- 完済日は購入日からちょうど35年後
- 2か月後セルは「YYYY/M時点」表記
- 推定残債は現在から3か月後時点で計算
- E23/E25相当の数式を7物件分、出力時に再設定
- テンプレートXMLに空欄セルが存在しない場合は自動生成して出力
- 抹消済みローンの判定・グレー表示を維持


## Ver.3.8.15 変更点
- Excel出力時に古い計算チェーン（calcChain.xml）を削除し、ダウンロードしたブックで修復警告が出る問題を修正。
- Ver.3.8.14の所有者名ファイル名・最新テンプレート・7件対応などはそのまま維持。
