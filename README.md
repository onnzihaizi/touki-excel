# 登記簿 → CS Excel Ver.3.8.13

Ver.3.8.12の機能・計算ロジックを維持したまま、ユーザー指定の最新版Excelテンプレート「最新版テスト(2).xlsx」へ差し替えた版です。

## 維持している仕様
- 最大7物件を1つのExcelへ出力
- 部屋番号は「113号室」の形式
- 完済日は購入日からちょうど35年後
- 2か月後セルは「YYYY/M時点」表記
- 推定残債は現在から3か月後時点で計算
- E23/E25相当の数式を7物件分、出力時に再設定
- 5〜7件目など、テンプレートXMLに空欄セルが存在しない場合は自動生成して出力
- 抹消済みローンの判定・グレー表示を維持

## Excelテンプレート
`sample/CS_登記簿自動入力.xlsx` は今回指定された最新版に更新済みです。
