# 登記簿 → CS Excel Ver.3.8.11

Ver.3.8.10の内容を維持したまま、1つのExcelへ最大7物件まで出力できるように拡張した版です。

## Ver.3.8.11 変更点
- PDFアップロード上限を4件 → 7件へ変更
- 5件目：O列側、6件目：R列側、7件目：U列側へ出力
- 5〜7件目にも部屋番号「号室」表記、購入日から35年後の完済日、時点表記、残債計算を適用
- 5〜7件目にも固定数式を再設定
  - Q23 / Q25
  - T23 / T25
  - W23 / W25
- 抹消済み抵当のグレー表示も5〜7件目に対応
- その他の抽出・計算ルールはVer.3.8.10のまま
